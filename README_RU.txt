# ФОРМА — архив художественной оценки

Это автономный сайт: ему не нужны npm, сборка или установка программирования.

## Быстрый запуск на компьютере

1. Распакуйте ZIP в отдельную папку.
2. Откройте `index.html` двойным щелчком в Chrome, Edge или Safari.
3. Добавляйте произведения, обложки и оценки.

Важно: локальный запуск подходит для знакомства с интерфейсом. Для постоянного использования на iPhone и более надёжной работы загрузки файлов и экспорта PNG лучше опубликовать сайт через GitHub Pages (HTTPS).

## Публикация через GitHub Pages

1. Войдите на https://github.com или создайте аккаунт.
2. Нажмите **New repository**.
3. Назовите репозиторий, например `forma-rating`.
4. Выберите **Public**, затем **Create repository**.
5. Нажмите **Add file → Upload files**.
6. Перетащите в репозиторий файл `index.html` из этой папки.
7. Нажмите **Commit changes**.
8. Откройте **Settings → Pages**.
9. В разделе **Build and deployment** выберите **Deploy from a branch**.
10. В Branch выберите **main**, папку **/(root)** и нажмите **Save**.
11. Подождите немного. Вверху раздела Pages появится адрес сайта вида:
    `https://ВАШ-ЛОГИН.github.io/forma-rating/`

## Установка на iPhone

1. Откройте полученную HTTPS-ссылку именно в Safari.
2. Нажмите кнопку «Поделиться» в Safari.
3. Выберите **На экран «Домой»**.
4. Подтвердите добавление.

## Как пользоваться

- Нажмите область обложки, чтобы выбрать изображение.
- Заполните название и сведения о произведении.
- Выставьте оценки по шести критериям. Итог рассчитывается автоматически из 100.
- Личный отклик хранится отдельно и не влияет на итог.
- Нажмите **Сохранить в архив**, чтобы добавить запись в локальную коллекцию.
- Нажмите **Сохранить PNG**, затем **Поделиться PNG** на iPhone. На компьютере можно открыть PNG отдельно и сохранить изображение через контекстное меню браузера.

## Важно о данных

Архив хранится локально в браузере на конкретном устройстве. Он не синхронизируется автоматически между компьютером и телефоном и может быть удалён при очистке данных браузера. Не очищайте данные сайта, если в архиве есть нужные записи. Рекомендуется периодически сохранять резервную копию архива, если в приложении будет добавлена такая функция.

## Если фото или PNG не работают

- Используйте актуальный Safari на iPhone или Chrome/Edge на компьютере.
- Открывайте опубликованный HTTPS-сайт, а не встроенный браузер Telegram или предпросмотр мессенджера.
- На iPhone для экспорта используйте системную кнопку **Поделиться PNG**. Если меню не появилось, откройте PNG отдельно и сохраните его через меню Safari.
